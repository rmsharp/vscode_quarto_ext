# Render and preview

- **Quarto: Render** produces the document's output file (HTML, PDF, and more, per its front matter).
- **Quarto: Preview** opens a live preview that updates as you edit and save.
- **Quarto: Render Project** renders an entire project (book/website) at once, from its root.

Use whichever command matches what you're working on — a single document or a full project.
