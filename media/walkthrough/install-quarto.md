# Install & verify Quarto

The Quarto CLI powers rendering, preview, and cell execution in this extension.

1. Install it from [quarto.org/docs/get-started](https://quarto.org/docs/get-started/) if you haven't already.
2. Run **Quarto: Verify Installation** to confirm the extension can find it on your `PATH`.

If verification fails, set the `quarto.path` setting to the executable's absolute path.
