# Run a cell, then explore more

**Quarto: Run Cell** (`Ctrl+Enter` inside a code cell) executes the cell under your cursor. **Run Cell and Advance**, **Run Cells Above**, and **Run All Cells** cover the rest of the family.

Beyond code cells, this extension also renders:

- **Preview Math** — live LaTeX math preview.
- **Preview Diagram** — live Mermaid diagram preview (with Graphviz `{dot}` block detection).

That's the full onboarding loop — install, write, run, render.
